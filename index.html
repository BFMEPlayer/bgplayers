Inżynieria Oprogramowania & Automatyzacja YT

Jak Prawidłowo Automatyzować Statystyki YouTube?

Wielu użytkowników pyta: "Czemu strona w samym pliku HTML nie odczytuje w 100% żywej liczby subskrybentów bezprzewodowo?"

1. Zabezpieczenia Google & CORS Restriction

Przeglądarki internetowe blokują bezpośrednie zapytania typu fetch() z zewnętrznych stron do prywatnych endpoints YouTube bez odpowiedniego klucza autoryzacyjnego API v3.

2. Klucz API (YouTube Data API v3)

Aby odczytywać w czasie rzeczywistym żywe dane kanału @BestGamePlayer-777 z serwerów Google, wystarczy wygenerować darmowy klucz w Google Cloud Console i wpisać go w górnym panelu tej strony!

Backend Node.js Script (Do uruchomienia na serwerze / VPS) 

// Automatic YouTube Sync Script (Node.js + Express)
const express = require('express');
const axios = require('axios');
const app = express();

const YT_API_KEY = 'YOUR_GOOGLE_YOUTUBE_API_KEY';
const CHANNEL_HANDLE = 'BestGamePlayer-777';

// Fetch Live Channel Stats Endpoint
app.get('/api/youtube-stats', async (req, res) => {
  try {
    // 1. Get Channel ID & Statistics
    const response = await axios.get(
      `https://www.googleapis.com/youtube/v3/channels?part=statistics,snippet&handle=${CHANNEL_HANDLE}&key=${YT_API_KEY}`
    );
    
    const stats = response.data.items[0].statistics;
    res.json({
      subscribers: stats.subscriberCount, // Live 12 Subs
      totalViews: stats.viewCount,       // Live total views
      totalVideos: stats.videoCount      // Live 32 videos
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

app.listen(3000, () => console.log('Server running on port 3000'));
